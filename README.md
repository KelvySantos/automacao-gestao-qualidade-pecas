# automacao-gestao-qualidade-pecas
Sistema em Python para automação do controle de qualidade e armazenamento em linhas de montagem industrial.

## 🌐 Demonstração online

- Landing page do projeto: https://kelvysantos.github.io/automacao-gestao-qualidade-pecas/
- Aplicativo web complementar: https://quality-box-manager--kelvysantosdev.replit.app/controle-qualidade/

## 🚀 Visão Geral

Este projeto automatiza a triagem, aprovação e organização de peças em uma linha de montagem industrial, reduzindo erros manuais, acelerando o processo e garantindo melhor rastreabilidade do material.

## 🧩 Funcionalidades

- Validação automática de peças por peso, cor e comprimento;
- Separação entre peças aprovadas e reprovadas;
- Organização em caixas por limite de capacidade;
- Relatório final consolidado do turno;
- Interface web complementar para acompanhamento visual do processo.

## 🖥️ Como executar a versão CLI

1. Clone o repositório;
2. Acesse a pasta do projeto;
3. Execute:

```bash
python main.py
```

## 📋 Critérios de qualidade

- Peso: 95g a 105g
- Cor: Azul ou Verde
- Comprimento: 10cm a 20cm

## 📦 Estrutura do projeto

- `main.py` — lógica principal do sistema em Python;
- `index.html` — landing page do projeto publicada no GitHub Pages;
- `README.md` — documentação do projeto.
